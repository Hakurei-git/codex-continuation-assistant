# Codex 自动续接助手 · 通用版

[下载 Windows EXE](https://github.com/Hakurei-git/codex-continuation-assistant/releases/download/v2.1/CodexContinuationAssistant.exe) · [所有发布版本](https://github.com/Hakurei-git/codex-continuation-assistant/releases)

独立社区工具，非 OpenAI 官方产品。

## 使用

1. 在 Windows 10/11 x64 上打开 Codex 桌面客户端，至少有两个未归档的本机聊天（被监测聊天及另一个用于接口上下文的聊天；后者不会因此收到消息）。
2. 双击 CodexContinuationAssistant.exe，无需安装 Python。
3. 选择“单对话”或“多对话”，勾选需要监测的聊天。
4. 设置检查间隔（10–86400秒，默认30秒）及重试等待（5–86400秒，默认30秒），点击“保存配置”，再点击“开始 / 恢复监测”。

聊天列表支持搜索、刷新；也可粘贴聊天 ID 核验加入。聊天名称变化不影响绑定。修改聊天、模式或间隔会立即暂停发送，保存后需再次开始。新安装不预选聊天；每次正常启动均暂停，不添加开机自启。

## 监控状态

重试倒计时和下次检查倒计时自动刷新；暂停后不继续倒数。最近活动随状态读取更新。列表分别显示“任务状态”和“监控状态”。任务执行中不代表助手在监测。

- 监测中：正在定期检查，符合条件后才发送。
- 等待审核：仍在监测；在原对话审核后自动重新判断。
- 等待回执：仍在监测，正在确认上一条发送。
- 等待重连：接口或状态读取失败，下轮再检查。
- 已暂停：点击开始后才能发送。
- 已停止：此聊天目标完成、删除、主动停止或达到重试上限；其他聊天不受影响。
- 未加入：未勾选此聊天，不会发送。

每个聊天独立保存授权、发送记录及重试次数。全局暂停/关闭窗口取消未发送的操作；已经提交的消息无法撤回。间隔是两轮检查之间的等待时间；一轮依次检查所选聊天，接口耗时会增加实际周期，轮次不会重叠。

## 自动继续的范围

普通聊天无需目标卡片也能监测；遇到临时失败时继续当前对话。曾经监测到目标、后来目标被删除时仍停止自动续接。仅对明确的限流、服务繁忙、临时网络超时或服务端暂时错误自动继续。每次重试都使用自定义的固定等待时间，不再递增为1、2、5、10、15分钟；最多连续6次。重试到期会提前核验，不必等待完整检查间隔。确认有新成功命令进展后重置次数。

回执等待期间每5秒核验；除了普通用户消息，还只读识别聊天历史中的跨任务消息回执，确认送达后恢复正常检查间隔。新的实际工作进展会立即重置连续失败次数。发送未确认超过2分钟，且实时核验仍为临时故障、未运行、无待审核请求时，将未确认发送计入次数，按自定义等待时间再次续接。遇到运行中、主动中止、认证/余额问题或无法判断的状态，不盲目继续。不能仅凭目标 blocked 就发送。

本工具发送续接消息，不等于点击 Codex 的“Resume goal”。本地接口未提供该按钮，必须点击时仍需手动处理。

## 限定范围自动授权

默认关闭。先保存配置，再高亮一个已加入的聊天，勾选该聊天的限定授权。不同聊天不继承授权。

仅对最新助手符合保守整句规则的项目内可回滚操作自动回复（例如“是否允许在当前项目中运行一次定向测试？”）。不自动批准正式存档修改、删除数据、付费、扩大权限、安全保护变更、突破一次性次数或恢复主动停止的接管。不代点系统或工具审批按钮。复杂或不明确的请求需要手动处理。

## 分发与兼容性

可只分享 EXE，也可分享此 ZIP。ZIP 不含个人聊天配置、聊天记录、日志、固定聊天 ID 或密钥。源码位于 source，供审查或自行构建。

程序自动发现本机 Codex 连接和聊天 ID。依赖 Codex 当前的本地命名管道，以及只读聊天/目标数据库结构；不同或未来客户端版本可能不兼容，无法保证任意版本都可用。不兼容时等待处理，不改 Codex 数据、不自动启动 Codex、不启动其他项目执行器。需要 Windows PowerShell 5.1 和 .NET Framework（常见 Windows 10/11 环境自带）；组织策略限制执行时可能无法打开。未签名的 EXE 可能被 SmartScreen 提示。

定时检查只更新发生变化的单元格，保留滚动位置和高亮，不重建整张列表；主动搜索或刷新聊天列表时会重建列表。

配置和日志保存在当前用户的 %LOCALAPPDATA%\CodexContinuationAssistant。只更新 EXE 会保留原设置。升级旧版自动迁移原选择和重试记录；不要分享此配置目录。
